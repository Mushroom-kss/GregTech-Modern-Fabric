# GregTechCEu Modern Fabric

GregTechCEu-Fabric: GTCEu for Fabric and Quilt.

## Documentation / Wiki

[GTCEu Wiki](https://gregtechceu.github.io/GregTech-Modern/)

It's designed for newer versions of GTCEu-M, may not suit this project.
